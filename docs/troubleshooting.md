# Troubleshooting

## Local

| Symptom | Fix |
|---|---|
| `PYTHON_VERSION_MISMATCH` from Spark | Spark workers picked up another Python. Set `PYSPARK_PYTHON=$PWD/.venv/bin/python` (conftest and the local runner already do this) |
| `JAVA_HOME is not set` / no Java | Install Java 17 (`brew install openjdk@17`); Spark tests are skipped automatically without it |
| `Binder Error: … does not have a column with name "run_id"` | DuckDB treated `run_id=` folders as Hive partitions. The loader passes `hive_partitioning = false`; keep it |
| `make local-airflow`: `command not found` | Paths with spaces need quoting; the Makefile quotes them. Run it from the repo root |
| `.env: command not found` when sourcing | Quote values containing `*` (e.g. `CDC_DAG_SCHEDULE="0 * * * *"`) |
| `SOURCE_DB_ADMIN_PASSWORD` missing | `cp .env.example .env` and set a local-only password |
| DuckDB "database is locked" | One writer at a time: close other sessions (`duckdb` CLI, notebooks) on `local_data/bigquery_local.duckdb` |
| Validation fails on demo data | The demo includes malformed rows on purpose. Local targets set `CDC_MAX_REJECTED_RATIO=0.5` |

## AWS

| Symptom | Fix |
|---|---|
| DMS test-connection fails | Check SG ingress 5432 from the DMS SG, the secret JSON keys (`username`, `password`, `host`, `port`), `rds.force_ssl` vs `ssl_mode` |
| DMS: `logical replication is not enabled` | Parameter group not applied: reboot RDS (`bootstrap_aws.sh` does this when pending) |
| DMS: slot errors | `03_enable_cdc.sql` creates `dms_cdc_slot`; or remove `slot_name` so DMS creates its own |
| CDC rows rejected with `invalid_sequence` / `missing_cdc_timestamp` | The header expressions aren't populated on your DMS version. Check `table_mappings.json` against the docs (docs/dms_setup.md) |
| Glue: `No module named cdc_common` | `--extra-py-files` must point at `dist/pipeline_libs.zip`. Run `make build` before `terraform apply` |
| Glue Python Shell: dependency install fails | Needs internet egress to PyPI (not in a VPC without NAT), or vendor wheels in S3 |
| Transfer: `google.auth … AWS` errors | Wrong WIF credential config or attribute condition. The role name in `infra/gcp` (`aws_transfer_role_name`) must match the Glue transfer role |

## GCP / BigQuery

| Symptom | Fix |
|---|---|
| `Not found: Table …_cdc_stage` | Run `deploy_bigquery.py --apply` (the load uses `CREATE_NEVER` on purpose) |
| Load error on NOT NULL column | Staging must allow NULLs except on the PK; redeploy the DDL generated by `make sql` |
| `StagingCountMismatchError` | Rerun `transfer_s3_to_gcs`, then the load; check `transfer_result.json` |
| MERGE "UPDATE/MERGE must match at most one source row" | Can't happen with the generated SQL (it dedups with QUALIFY). If you edited the SQL, restore it with `make sql` |
| Costs higher than expected | Check `INFORMATION_SCHEMA.JOBS` for `labels.pipeline = 'aws-rds-cdc'`; confirm clustering; see COST_NOTES |
